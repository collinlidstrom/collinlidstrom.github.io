# Collin Lidstrom — personal site

A dependency-free static site published with GitHub Pages at https://www.collinlidstrom.com.

## Editing

- Homepage and positioning: `index.html`
- Work and project stage labels: `projects/index.html`
- Career information: `resume/index.html`
- Shared visual styles: `assets/css/brand.css` (loaded after legacy `styles.css`)
- Theme and mobile navigation: `assets/js/site.js`
- Social preview image: `assets/og-card.png`

Preview locally with `python -m http.server 8000`, then open http://localhost:8000. Keep project stages, work dates, and public claims current as they change.
